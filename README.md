## Описание

**ArtSpace** — платформа для поиска концертов, выставок, спектаклей и других культурных событий.
Пользователь выбирает направление (музыка, живопись, театр, фотография, современное искусство),
находит подходящие события, изучает подробности и записывается на посещение.
Все события и площадки вымышлены (учебный проект).

## Используемый фреймворк

Bootstrap 5.3.8 (+ Bootstrap JS Bundle).

## Подключение Bootstrap

Через CDN (jsDelivr). `css/custom.css` подключён **после** Bootstrap.

Чтобы подключить локально (дополнительное задание): скачать compiled-версию на
<https://getbootstrap.com/docs/5.3/getting-started/download/>, положить файлы в
`vendor/bootstrap/css/bootstrap.min.css` и `vendor/bootstrap/js/bootstrap.bundle.min.js`
и заменить ссылки в `<head>` и перед `</body>` на локальные. После этого поправьте этот раздел README.

## Страницы

| Файл | Содержание |
| --- | --- |
| `index.html` | hero, о платформе и преимущества, популярное на неделе, направления, подборщик события, статистика |

## Реализованные компоненты Bootstrap

`container / row / col-* / g-*`, `navbar` (sticky, collapse, dropdown), `breadcrumb`, `card`, `btn`, `badge`,
`alert` (в т. ч. dismissible), `modal`, `form-control`, `form-select`, `input-group`, `form-check`,
`accordion`, `nav-tabs`, `list-group`, `table-responsive`, utility-классы отступов, цветов и выравнивания.

## Самостоятельные доработки

- пятая страница `contacts.html` с формой обратной связи и FAQ на accordion;
- фильтры каталога без перезагрузки: направление, город, дата, цена, формат, поиск, сортировка, снимаемые метки;
- переход с главной в каталог с готовым фильтром (параметры в адресе: `catalog.html?category=music`);
- подборщик «Какое событие вам подходит» (3 вопроса → каталог с фильтром);
- страница события формируется по `?id=`; вкладки, тарифы, ссылка «Другие события организатора»;
- проверка форм с сообщениями об ошибках и сводкой заявки (на Bootstrap-классах `is-invalid` / `is-valid`);
- метки «Хит», «Последние билеты», «Онлайн», «Для всей семьи» (badge), кнопка «Наверх», закреплённое меню, якорные ссылки;
- собственные стили в БЭМ + CSS-переменные, Flexbox и Grid в `custom.css`; доступность: подписи полей, видимый фокус, skip-ссылка.

## Как проверить

1. Открыть `index.html`, пройти подборщик — откроется каталог с фильтром.
2. В `catalog.html` менять фильтры, снять метку, нажать «Кратко».
3. Открыть событие, отправить пустую форму (ошибки), затем корректную (сводка заявки).
4. Проверить адаптивность в DevTools: 375, 768, 1024, 1440 px.
